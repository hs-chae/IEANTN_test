# A→B composition pilot (integration workstream, Agent B)

This is a research pilot. It is **not** a node solution, not part of the core build, and it adds
no node version. It shows a two-executable chain built from existing interfaces:

`MT.v2.corollary_1` or the QRH θ bound → **program A** (calibration deviation at `L₀ = 9400`)
→ two-sided π expansion `π(x) = S₅(x) + (120 ± Δ)·x/(log x)⁶` for `x > e^9400`
→ **program B′** (the frozen Ramanujan budget program, re-instantiated)
→ quantitative Ramanujan gap for `x > e^9401`.

## Modules

- Written by hand:
  - `NamedSource`: the frozen selected-sum wrapper with a configurable entry-point name. Soundness
    is the frozen `source_linked_upper`, reached through `to_exec`.
  - `Adapter`: v4's coefficient theorem with its constants as parameters, plus the monotonicity
    that carries the endpoint value to the whole ray (`calibrated_pi`).
  - `OldInput`, `NewInput`: the analytic θ inputs and the kernel bounds on the small pieces.
  - `OldChain`, `NewChain`, `KernelA`, `KernelChain`.
- Generated by `generate_pilot.py`: `OldA`, `NewA` (program A instances), `OldB`, `NewB`
  (program B′ instances), and `c/*.c`.
  - B′ comes from the **frozen** generator `Solutions/RamanujanNumerics.v1/generate.py`, imported
    as a library. Its scale constant is turned into a parameter. At 4096 the result is
    byte-identical to the frozen generator (`generated_fidelity.json`).
  - The old configuration needs scale 8192, because the frozen family admits inputs ≤ 1, so
    `2M ≤ 4096`.

## Trust

- Analytic premises: `MT.v2.corollary_1`, or `QRHCH2.v5.psi_refined_bound` (which depends on 13 CH2
  premises and the QRH theorem upstream).
- Finite `native_decide` facts as counted above.
- Restricted C/RN64 semantics.
- The compiler, runtime and hardware are trusted. GCC output bits match the modelled bits; this is
  a diagnostic, not part of the proof.
- No official receipt. Controlled replay: the QRH input was known in advance.
