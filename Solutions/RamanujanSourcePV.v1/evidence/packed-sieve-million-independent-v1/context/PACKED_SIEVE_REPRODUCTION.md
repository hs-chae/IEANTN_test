# Exact packed sieve experiment

This experiment uses geometric binary masks to classify the unchanged two local windows: 1,000,000 integers starting at 38,358,837,684 and 367,880 integers starting at 14,111,427,771. The expected counts are 40,916 and 15,972. Those expectations and the generated hexadecimal masks are proposals; they become evidence only when the corresponding Lean kernel proofs compile.

The generic proof identifies every mask bit with `Nat.Prime`, proves exact byte population counting and padding, and supplies the existing actual C segmented checker with explicitly represented inputs. The source checker computes its own sieve and accepts only matching flags. `PackedSieveProvider.source_provider` consumes that actual modeled C execution and produces every prefix count. Its ownership, allocation, input-word and source-byte correspondence obligations are proved. This does not claim a verified physical loader or a verified native C implementation of the packed-mask algorithm.

## Regenerate the numerical proposals

Use the pinned Lean and Mathlib environment described by the main reproduction instructions. The generator itself needs Python 3's standard library and has no random input.

```sh
python3 scripts/generate_packed_sieve_primitive.py --mask-only --out /scratch/packed-proposal
```

The output directory must be new. This generates two proof sources and a manifest containing the parameters, generator and source hashes, bit-mask hashes and interpreter version. Normal, `-O` and `-OO` runs generated byte-identical proof sources; see `evidence/PACKED_SIEVE_PROPOSAL_REGENERATION.json`.

## Compile from fresh application objects

Create the pinned generic-library context using the project's clean-environment setup. The command below uses the existing fresh-closure controller; it recompiles application sources rather than using the project's application-object cache.

```sh
python3 scripts/reproduce_profiled_closure.py \
  --context BUILD_CONTEXT.json --out /scratch/packed-fresh-proof \
  --application-source-root . \
  --application-source-root /scratch/packed-proposal/source \
  --root RamanujanPV.PackedSievePrimitiveMaskMillion \
  --root RamanujanPV.PackedSievePrimitiveQWindow \
  --theorem RamanujanPV.PackedSievePrimitiveMaskMillion.packed_bits \
  --theorem RamanujanPV.PackedSievePrimitiveQWindow.packed_bits \
  --theorem RamanujanPV.PackedSievePrimitiveQWindow.raw_byte_result \
  --jobs 1 --memory-gib 192 --aggregate-gib 192 \
  --host-reserve-gib 512 --cpus 32
```

Check the resulting receipt with the same controller's `--check` option. The P mask is sealed once; the selected `PackedSieveQueries` theorem checks all 285 original P/Q prefixes using disjoint byte slices. This avoids a redundant 125,000-step whole-P popcount. The exact mathematical mask remains unchanged: `PackedSievePrimitiveBits.primitiveBits_eq` proves that the fast XOR/AND expression equals the original bitwise difference.

The resource policy requires genuinely available RAM and independently available disk; a memory ceiling is not a measurement of actual peak RAM. The command is a reproduction procedure, not a claim that the currently running large numerical proofs have passed.

## Evidence and boundaries

`evidence/PACKED_SIEVE_SCALABILITY_CHECKPOINT.json` records accepted generic proof sources, hashes, compilation receipts and actual axiom reports. The standard Lean axioms are disclosed; no `sorry`, new axiom or `native_decide` result supplies the numerical provider. Small raw numerical controls are kernel-only until combined with the generic mathematical and C-source consumers. The failed 48 GiB million-point attempt is retained separately; GMP reported allocation failure, and it must not be described as an observed OS OOM kill.

The new `PackedSieveMillion.first_1000001_real_interval` and `PackedSieveMillion.uniform_gap` have compiled with the unchanged mathematical conclusions: every real x from 38,358,837,683 (included) to 38,359,837,684 (excluded) satisfies the Ramanujan inequality, and its gap exceeds 501,901. All 285 original P/Q prefix values are checked from the sealed masks using disjoint slices. The old Lucas-provider dependency exclusion is checked separately by the independent selected-proof audit; that gate must pass before claiming complete replacement. Whole-window population counts alone would not establish it. The global finite Ramanujan range and the separate high-height prime-count campaign are outside this experiment's completed scope.
