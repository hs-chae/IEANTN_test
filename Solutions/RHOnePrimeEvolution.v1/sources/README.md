# Pinned original mathematical sources

SOURCE_URLS.json identifies exact versions, URLs and SHA-256 values. fetch_sources.py retrieves and verifies the pinned originals into a fresh owned directory. Download success only establishes byte identity; source theorem truth and numerical verification status are separate.

Nicely’s2019 primary document reports analysis of consecutive-prime gaps below2⁶⁴, with maximal gap1550 and practical/completeness qualifications. The original334,665-byte PDF is preserved here because the current scripted OEIS request returns HTTP403. Its first page expressly releases the material into the public domain. The downloader verifies the preserved copy against the original SHA-256 and explicitly records archived fallback use, not a successful remote fetch. This does not newly verify the historical prime computation.

The six other primary files were successfully fetched and matched during the reproduction check. Their full text is preserved as research evidence outside the publishable package; the small public script downloads the exact originals when needed. Failed retrieval receipts are retained separately and are never used as evidence of source absence.
