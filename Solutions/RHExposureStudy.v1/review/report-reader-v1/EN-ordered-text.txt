[L2] h2 Three mechanisms of actual reuse

[L2] p 1. A hypothesis supplies a typed input, not a new numerical table. The new RH node is the exact Mathlib proposition and is intentionally unproved. The proved adapters supply every required finite-height RH rectangle and every open zero-free half-plane with boundary at least one half. Existing proof bodies then consume those values. The full arm also proves the relevant density index is empty under RH. It does not substitute one half into a theorem restricted to seven eighths, or pretend that zero locations supply counts and moments.

[L2] p Concrete example: the old reciprocal-ordinate cap 10.3194 is not obtained from RH alone. A new proof uses the existing zero-count contract and antitone Lehman lemma to prove the weaker 11.1404 cap. Because this cap enters CH’s scaled error additively, the numerical input can be removed at an explicit cost 0.821√x. This is a meaningful reduction of assumptions even when another written formula has a smaller coefficient.

[L2] h2 Which IEANTN objects made propagation possible

[L2] p A node version names precise propositions in Conclusions.lean and records permitted dependencies. Vocabulary fixes the actual prime functions, errors and zero-free regions. A solution provides proof terms with those inputs as explicit parameters. Bridges translate between compatible definitions or parameter domains. Generated challenges specify the requested interface; a challenge file containing a placeholder is not a proof. Comparator metadata and graph checks verify the packaging, while Lean checks the actual theorem.

[L2] p Adding RH therefore changes which input proofs can be supplied. It does not automatically discover a sharper height, recover a sign discarded by an old bound, or verify an existing numerical program. In this experiment those required new mathematics: choosing T(x), reconstructing signed J deficits, retaining a spectral primitive, and composing source-linked counts with a new real-variable consumer. The network provided reusable contracts and proof bodies, including the Costa Pereira prime-power and PrimeInterval θ-count bridges. NL was allowed to reconstruct any such mathematics and did develop independent smoothing and sieve proofs. Actual reuse shows a mechanism, not exclusivity.

A completed finite-source count remains missing on the stated large prefix. None of these failures shows that another method is impossible.
