승인된 연구 체크아웃을 97c2f6bf91b8ac1eff6a298557c05e25aa1a97bf로 고정했다. RH 관련 두 계열을 추가하기 전 노드 계열 62개, 버전 118개, 결론 258개였다. 실험군에는 실패한 원형을 포함한 추가 소스·상태 파일 885개 전부를 제공했으며 성공한 일부만 추리지 않았다. 실시간 확인한 공식 upstream 커밋 d60421f10c16f5f6c2cb75f1067a72e24e616391은 달랐다. 그 소스도 별도로 보관·제공하되 연구 패키지를 덮어쓰지 않았다. 따라서 이전에 도출된 수학까지 포함하는 전체 패키지 노출 실험이며 순수한 그래프 표현 효과만의 실험은 아니다.

각 작업자는 새 네이티브 세션에서 동일한 gpt-6.2-sol/high 설정, 동일 바이트의 공통 문제, 동일한 Lean 4.34.0-rc2 / Mathlib 71a80585 도구를 사용했다. NL에는 IEANTN 응용 소스나 오브젝트를 제공하지 않았다. 각 작업자는 독립 Linux 사용자·마운트·PID·네트워크 네임스페이스, 전용 쓰기 작업 공간, CPU affinity 8개, RAM 한도 96 GiB, 임시 저장 허용량 64 GiB를 가졌다. 호스트 전체나 자격 증명은 마운트하지 않았다. 중립적인 요청자별 문헌 브로커로 더 넓은 수학 문헌에 접근할 수 있었다. IEANTN 작업자는 현재 소스 패키지를 보았지만 worktree 포인터 밖의 Git 이력은 마운트하지 않았다.

과학적 비교 시점은 900초, 1,800초, 3,600초로 미리 정했다. 기술 스냅샷은 매분 저장했으나 여러 파일의 원자적 최종 제출은 아니다. 두 최종 결과는 별도로 작업을 멈추고 해시를 확정했다. NL은 3,684.914초, IEANTN은 4,205.528초 후 제출했다. 같은 시점 스냅샷은 시간 일치 비교에 사용하며, 최종 결과는 시간이 다르므로 별도로 보고한다. 확정 이후 증명 구현과 합성은 추가 조정자 작업이며 원 실험의 성공으로 소급하지 않는다.

공통 문헌 요청 도구의 스키마 결함으로 초기 요청이 실패했다. 도구는 kind/value를 출력했지만 초기 브로커는 url/query를 기대했다. 최초 결함 조사에서 NL 20회, IEANTN 10회 실패를 관찰했다. 900초 비교 시점 전에 두 연구군에 동일한 추가 수정을 적용했고 실제 격리된 도구로 시험했으며 모든 원 실패 기록을 남겼다. 서로 다른 손실 노력은 실제 한계다. 다운로드 실패, 거부된 URL, 찾지 못한 문헌은 수학적 실패나 문헌 부재의 증거가 아니다. 이 결함을 포함한 한 쌍으로 일반적인 확률적 우위를 주장할 수 없다.
