Which IEANTN objects made propagation possible

A node version names precise propositions in Conclusions.lean and records permitted dependencies. Vocabulary fixes the actual prime functions, errors and zero-free regions. A solution provides proof terms with those inputs as explicit parameters. Bridges translate between compatible definitions or parameter domains. Generated challenges specify the requested interface; a challenge file containing a placeholder is not a proof. Comparator metadata and graph checks verify the packaging, while Lean checks the actual theorem.

Adding RH therefore changes which input proofs can be supplied. It does not automatically discover a sharper height, recover a sign discarded by an old bound, or verify an existing numerical program. In this experiment those required new mathematics: choosing T(x), reconstructing signed J deficits, retaining a spectral primitive, and composing source-linked counts with a new real-variable consumer. The network provided reusable contracts and proof bodies, including the Costa Pereira prime-power and PrimeInterval θ-count bridges. NL was allowed to reconstruct any such mathematics and did develop independent smoothing and sieve proofs. Actual reuse shows a mechanism, not exclusivity.
