RH080 연구의 수학적 요약
2026-11-26 · 최종 W4 검증 전 원고

이 연구는 RH를 증명하지 않습니다. RH와 명시된 해석적 문헌 명제를 가정하여 소수 구간·소수 개수 정리를 증명하고, 일부 수치 경계를 실제 C 소스의 실행 의미론과 연결합니다. 문헌의 해석적 증명과 과거 소수 간격 계산은 이름이 붙은 가정으로 남아 있습니다.

받아들여진 유한 구간 정리는 다음과 같습니다. 모든 실수 x에 대하여, 두 끝점이 열린 구간
  x < p < x + c√x log x
안에 소수가 존재합니다.
  c = 0.8: 4 ≤ x ≤ exp(174)
  c = 0.74: 11 ≤ x ≤ exp(63)
  c = 0.75: 11 ≤ x ≤ exp(70)
이 세 결과는 RH와 여덟 문헌·과거 계산 입력을 사용합니다. 별도로 4 ≤ x < 11에서 c = 0.777은 무조건적인 커널 증명입니다. 실제 수치 노름과 일반화된 영점 부분합 공식은 최종 조합에서 추가 가정으로 남기지 않고 증명된 제공자를 사용합니다. 681개 모듈의 같은 실험 소스 재구성과 독립 최종 게이트도 통과했습니다. 검증된 소스 재구성 접두부 357개와 새로 컴파일한 후속 324개로 이루어지며, 하나의 새 실행에서 681개 전부를 다시 컴파일한 결과로 부르지 않습니다.

점근적 가우스 증인은 정확한 계수
  q = 20582561296 / 24680948495 < 0.833945313
을 주며, 명시적인 시작점은 없습니다. 이 결과는 수학적 커널 증명이지 PV가 아닙니다. 같은 CMS 함수 최적화 문제에서 전체 실수·짝함수·연속 L1 클래스에 대해 100/123 > 0.8이라는 쌍대 하한을 소스 우선 C 검증과 Lean으로 연결했습니다. 문헌 하한 50000/60393, 새 외부 Arb 하한 2000/2399, 가우스 상한 q는 검증 수준이 서로 다릅니다. 특히 새 Arb 하한은 Lean 또는 소스 우선 PV로 승격하지 않았습니다. 이 하한은 실제 소수 간격의 하한이 아니며, 유한 구간의 0.74와 모순되지 않습니다.

소수 개수에서는 Good(α,c)를 “c > 0이고, 어떤 δ > 0에 대해 충분히 큰 x에서 해당 반열린 구간의 소수 개수가 (α+δ)√x 이상”이라는 뜻으로 씁니다. 끝점에서 infimum만 얻는 것과 실제 Good 성질을 얻는 것을 구별합니다. 기존 작은 C 프로그램 두 개는
  S(α) = 0.944247 + 1.163388α
  F(α) = 9/8 + (16/15)α
를 실제 Good 계수로 제공합니다. 같은 수학적 사실을 쓰는 커널 전용 대조군도 같은 계수를 증명합니다.

별도의 순수 해석적 개선은 모든 정수 m ≥ 1에 대해
  c_m(α) = [2m/(2m−1)] [α + (1+log(4m−2))/π]
를 줍니다. α ≥ 0, ε > 0이면 Good(α,c_m(α)+ε)가 성립하고, Good 계수 집합은 비어 있지 않으며 그 infimum은 c_m(α) 이하입니다. ε = 0에서의 실제 Good 성질은 주장하지 않습니다. 첫 m개 노드만 1인 평탄 스펙트럼에서 F(0) = (2m−1)/m, 외부 양의 누출 J = 0, 최대값 M = 1을 정확히 계산합니다. 디리클레 항등식과 코시컨트 적분으로 실제 노름을 제한합니다. 이 경로는 일반 BR 노름 명제, q = 1 개수 명제, RH만 사용하며 수치 프로그램이 필요 없습니다.

밀도를 실수 α로 보내는 결과도 Lean으로 증명했습니다. m = ⌊πα/2⌋+1을 택하면, 모든 η > 0에 대해 충분히 큰 실수 α에서
  Good(α, α + log(α)/π + K + η),
  K = (2+log(2π))/π ≈ 1.2216342122
가 성립합니다. 같은 계수에 대한 비어 있지 않은 집합과 infimum 경계도 증명했습니다. 먼저 밀도 α를 고정한 뒤 소수 변수 x의 문턱을 얻으며, α와 x에 대한 공동의 균일한 시작점은 주장하지 않습니다. 이 결과 역시 순수 해석적 커널 증명이며 PV가 아닙니다.

고정 m = 64에서는 여유를 따로 증명하여 2.1 + (128/127)α 자체가 Good 계수가 됩니다. 밀도 40의 폭은 정확히 53867/1270 ≈ 42.414960630입니다. Lee의 arXiv:2403.11814v4 정리 1.1은 식 (2)에서 L ≈ 1.542627287776을 정의하고, 식 (4)에서 θ 오차를 제한합니다. 여기서 직접 유도한 밀도 40의 문턱은 약 42.737908384입니다. 새 계수는 이 특정한 직접 귀결보다 작습니다. 모든 문헌 결과보다 우수하다거나 최적·최초라는 뜻은 아닙니다. 소수 개수 직접 귀결의 식은 c − log(c)/π − L이며, 그 경계의 등호만으로 양의 여유를 얻지는 못합니다.

소스 우선 PV는 실제 C 문자와 독립적인 구문 관계, 실행 모델, 해당 프로그램의 수학적 정확성, 최종 소수 정리에서의 사용을 연결합니다. 프로그램의 초기화·버퍼·반복·반올림·출력을 증명하지만, C 컴파일러나 운영체제 자체를 검증했다고 주장하지 않습니다. 문서화된 일반 컴파일러·런타임·ABI·API·하드웨어 계약은 신뢰 경계로 남습니다. 실제 실행이 같은 정수를 출력했다는 관찰만으로 PV가 되는 것도 아닙니다.
