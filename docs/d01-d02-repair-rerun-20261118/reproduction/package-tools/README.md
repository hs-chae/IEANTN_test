# Public evidence package preparation

This directory prepares a source inventory and deterministic packaging commands. No scientific run, model call, publication, upload or public package build has been performed here. Root must review the actual inventory, every flagged schema/nested member, final comparison assets and final all24 numerical-source archive before approving a build. Pending assets are explicit; an old prepared archive cannot stand in for an unperformed numerical replay.

The package preserves the full readable standalone report as `report.html`, the same human content as `report.md`, the separate mathematical exposition, all24/48 public data, every latest complete accepted floor, source/domain audits and corrections, exact locked candidate/public mathematical-review payloads, seven original PDF/text pairs, actual numerical/resource/readback/authority receipts and every durable output. It includes only source archives named by actual replay evidence; unused prepared versions are not selected. The eleven pinned compressed plotting wheels and their embedded licenses support offline figure regeneration without copying installed environments. Final24 figures and final all24 numerical source/recipe manifests must be supplied at their accepted final pins.

All selected bytes are hashed without being copied. The scanner reads actual JSON and JSONL fields and recursively inventories every ZIP/tar member, rejecting unsafe paths and links. Mathematical command/output JSONL is inspected by schema, not confused with a private native-event transcript based on its extension. Raw private contexts, messages/reasoning, credentials, memory, installed environments and cache/negative-fixture paths require rejection or explicit Root byte-level adjudication; a filename allowlist alone is insufficient. Source-associated controller-result metadata is included only when actually required by the locked source or durable replay and after this schema inspection. The full private inventory is a review input, not a public artifact.

Plain `accepted-floors/*.json` and the main public data remain plain to preserve actual report links. Large repetitive ancillary JSON is individually gzipped with empty filename/mtime0, with both original and compressed hashes recorded. The outer tar uses the existing portable-source archiver's conventions: sorted regular files, mode0644, empty owner names, uid/gid/mtime0; gzip filename and mtime are fixed. Source, algorithm, parameters, output contracts and actual source archives are never rewritten. The manifest records the original-to-public member mapping and hashes. Attachment parts are at most6,700,000bytes; their count is determined by the complete evidence, not an arbitrary total-size cap.

Prepare a fresh source-only inventory:

```
python3 -I -B prepare_inventory.py --snapshot SNAPSHOT/ALL24_PUBLIC_SCIENTIFIC_STATUS.json --human-html SNAPSHOT/MAIN_REPORT_COMPLETE_REVIEW_DRAFT.html --out FRESH_INVENTORY.json
python3 -I -B package_evidence.py --inventory FRESH_INVENTORY.json --check
```

The `--check` command without authority is only a source/schema readback. It never claims publication approval. A build requires an exact Root approval with status `ROOT_APPROVED_EXACT_PUBLIC_EVIDENCE_PACKAGE_BUILD`, `reviewed_by` `/root`, the exact inventory SHA, no pending required assets, and explicit SHA-bound dispositions for any flagged actual bytes. No such final authority is issued by this helper.

After that review and approval only:

```
python3 -I -B package_evidence.py --inventory FINAL_INVENTORY.json --Root-approval ROOT_APPROVAL.json --check
python3 -I -B package_evidence.py --inventory FINAL_INVENTORY.json --Root-approval ROOT_APPROVAL.json --out FRESH_PACKAGE_DIRECTORY
```

Reconstruct downloaded attachment parts using Python3's standard library:

```
python3 -I -B verify_and_reconstruct.py --manifest PUBLIC_MANIFEST.json --parts DOWNLOADED_PART_DIRECTORY --out FRESH_evidence.tar.gz --extract FRESH_EVIDENCE_DIRECTORY
```

This checks every part, whole archive, exact member and each individually compressed JSON's original hash before reporting success. Extraction accepts only the exact manifest's safe regular files and a fresh directory. Extraction retains each compressed ancillary JSON member and also restores its exact original `.json` path after a complete destination-collision precheck and original SHA/length verification. Main report JSON/floors are plain. Large downloadable frontier JSON may still be compressed for direct download; its exact original is restored on extraction. Opening `report.html` needs no extension, CDN, model, API, authentication or installed plotting environment. Numerical or figure regeneration is a separate procedure with its exact dependencies/parameters/source/runtime/command receipts, not a consequence of successful archive reconstruction.
