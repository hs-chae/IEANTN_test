# Work and limitations
Draft and early routes retained. A naive absolute Ψ tail in the Mertens transfer costs asymptotically a factor nine at exponent 7/8; keeping a common finite explicit-formula cutoff and integrating oscillations avoids it. Merely using bounded finite-height Ψ error for an infinite integral fails because the constant-relative part is not integrable against 1/(x log x). Instead use the actual CH2 weighted sum or QRH/zero density.
Single coarse beta split produced unnecessarily large constants; the mesh keeps cumulative zero counts and telescopes rather than adding nested counts repeatedly. Upper-staircase and finite real-cell checks are proved; diagnostic samples are not inputs. Exact right endpoint sieve exposed a defect in the literal real onset printed by PT. No use of that clause for nonintegers.
C exploratory .13/L³ from 9 million and .17-equivalent sqrt mode (coefficient 1.7) on the whole finite interval fail with the present proof, not necessarily at actual prime inputs. Early weighted-sum code approximated from p=2 with wide blocks and lost ~.011; replaced by exact direct log for initial primes. C code is checked as an ordinary exact numerical certificate; no kernel or source-first PV of original computations claimed.

After the 75% lock, the integrated identity (S1) replaced variable-height truncation loss for the signed Mertens and primorial applications. The factorial lower margins likewise retained the earlier margins and added certified polynomial rungs. Treating the raw unsmoothed formula as uniformly convergent was not used. The estimates for actual high-ordinate signs remain unavailable; thus there is no sign conclusion for every primorial. The short prime interval/nearly extremal totient consequence is not a claim about global best constants.
The exact C run through 72,004,899,338 with only elementary tails for both constants had zero product failures but 42,626 reciprocal-sum enclosure failures; tightening the constants via Dusart 4.2 eliminated all failures in the final supported run. The 8,643,264 finite blocks then all passed for coefficients 2,2,2.1 in sqrt mode. The small-x certificate uses a different, slightly larger coefficient 2.4; its 2.0 trial lacked enough margin. The final proof uses both finite block monotonicity and explicit continuous tail bounds, not merely a grid evaluation. Existing original computations, particularly sign at the small integers in the Ramanujan application, are not independently replayed globally. The new endpoint uses an independent sieve, and the new scalar and block checks are exact within the indicated executor semantics.
