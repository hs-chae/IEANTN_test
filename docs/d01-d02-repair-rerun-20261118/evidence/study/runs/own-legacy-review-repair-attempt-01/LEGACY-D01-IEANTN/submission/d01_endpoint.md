# Exact real Ramanujan endpoint
Let N=38358837682, K=14111427770. The standalone inclusive odd sieve endpoint.c obtains π(N)=π(N+1)=1644673232 and π(K)=632207037. It also verifies primality/compositeness near N and K, in particular N+1 is composite. The bounds on e show K≤N/e≤(N+1)/e<K+1. Thus both counting functions are constant on [N,N+1]. On that interval R(x)=e·632207037·x/log x−1644673232² has strictly positive derivative, and a unique root α with α−N between .2179263651446 and .2179263651448 (certified in endpoint.py). The derivative also lies between 67,000,000 and 68,000,000, so for α<x≤N+1 the gap is >67,000,000(x−α).
For integers n≥N+1 with n≤exp(58) retain the inherited PT Thm. 2 claim, restricted to integers. On [n,n+1), π(x)=π(n) and (ex/log x)π(x/e) is nondecreasing for n≥e, so extends to real x≥N+1 through the analytic ray beginning at exp(30.5). R(α)=0 precludes any smaller entire positive ray.
**Literal vs supported:** PT's p.3 literal open real endpoint N does not survive the certified endpoint calculation; for example R(N+.2)<0. We quote it as printed in baseline comparisons but do not use its real assertion in this interval, only its integer part. The new root statement retains the original trust of the integer computation; the count and root calculation near N are independent checks.
Build and run: `/usr/bin/gcc -O3 endpoint.c -o /work/endpoint && /work/endpoint > /work/endpoint.out`, then `/usr/bin/python3.10 -B endpoint.py /work/endpoint.out`. The sieve marks odd multiples starting at p² (or first odd multiple in each segment); each odd composite is hit by a prime divisor at most its square root. Counts include prime 2. No assumed prime table. Segments tile odd integers exactly and all counters fit in 64 bits.
