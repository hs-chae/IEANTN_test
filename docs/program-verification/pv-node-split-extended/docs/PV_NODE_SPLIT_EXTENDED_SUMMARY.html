Should verified programs be IEANTN nodes? Extended study

Agent B · 2026-11-06 · upstream teorth/IEANTN@466b41b, PoC hs-chae/IEANTN_test@qrh-2pv_B 3280a3c, Agent A 091288d (read only)

No architectural change. Programs, certificates and native facts stay evidence inside solutions. A numerical result gets its own node only when its evidence is a citation, when two consumer families import it, or when it keeps a native proof out of a consumer that would otherwise pass Comparator. The existing graph already follows that rule. The gaps that matter are source freshness and drift, and they do not depend on the layout.

What broke under change

  • Stale certificate. Editing one literal of program B′'s C file rebuilt nothing and the build passed, in both layouts. Declaring the two files to Lake (15 lines) makes the same edit fail, so the passing build was stale. 7 of the 12 PoC projects that read C files declare none of them (20 files).
  • Invisible drift. solution_drift reported nothing for the node's own project in every cross-project edit. A 32-line patch reports them; its tests fail before and pass after; upstream's 357 tests pass.
  • Source edits Lake can see (Table 4, declared input file): a newline rebuilt and passed; a comment or one changed digit failed at the certificate. No fingerprint moved. B's consumer was never rebuilt.
  • Program A's output weakened: the data link failed. In B the consumer failed too: its solution imports program A's module.
  • Imported statement changed (ψ profile constant): one fingerprint moved; in-memory receipts went BROKEN for A's consumer and B's provider, while B's consumer stayed green.
  • Route swapped (kernel → native, same statement): one module rebuilt, no fingerprint moved, no node or version involved.
  • Compiler flags: one program's result is 1 ulp lower under x87; nothing tracks flags, correctly, since no proof uses a binary.

Corrections to the first study

  • The leaf-set finding is one re-designation (Rosser–Schoenfeld zero-free region, 6af2f7a), not four. Four conclusions are flagged. Re-designating the paper proof (one line) passes upstream's check.
  • "Only PlattTrudgian is shared" holds only for direct consumers of computation-kind nodes. DudekPlattNumerics.v5 has two consumer families.
  • The old R3 test only said "the evidence is a citation"; the budget criterion R4 does not hold (a split moves the memory peak, it does not lower it).
